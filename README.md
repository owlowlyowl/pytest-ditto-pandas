# pytest-ditto-pandas (archived)

This repository is archived. `pytest-ditto-pandas` now lives in the main
[pytest-ditto](https://github.com/owlowlyowl/pytest-ditto) repository, under
[`plugins/pandas`](https://github.com/owlowlyowl/pytest-ditto/tree/main/plugins/pandas),
and is released from there at the same version as pytest-ditto itself.

- **pytest-ditto 2.x**: use `pytest-ditto-pandas` 2.x, from the main repository.
  It's also available as the `pandas` extra: `pytest-ditto[pandas]`. Upgrading from
  1.x? See the [upgrade guide](https://owlowlyowl.github.io/pytest-ditto/guides/upgrading/).
- **pytest-ditto 1.x**: `pytest-ditto-pandas` 0.1.2, built from this repository,
  is the last release. It requires `pytest-ditto>=1.0.1,<2`. Earlier 0.x
  releases are yanked.

Report issues and send pull requests to
[pytest-ditto](https://github.com/owlowlyowl/pytest-ditto/issues).
